# Student Success AI — Internship Project

## What it does
A small interactive dashboard that explores student learning indicators, trains a Random Forest classifier, estimates pass/at-risk status for entered sample values, and suggests study actions.

## Run it on a computer
1. Install Python 3.9 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the app:
   `streamlit run app.py`

## Files
- `app.py` — complete Streamlit application.
- `sample_student_data.csv` — small synthetic demonstration dataset.
- `Project_Report.pdf` — project report for review/submission.
- `requirements.txt` — Python dependencies.

## Important
The dataset is synthetic and contains no real student records. The model is for learning/demo purposes only. Do not treat its output as a guaranteed result or use it for high-stakes decisions.
